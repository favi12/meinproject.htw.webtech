# meinproject.htw.webtech
Webtech Java Projekt
Anwendung für Sportler um Wettkämpfe und das Kommunikation innerhalb zu organisieren. 
Die Anwendung wird in Frontend und Backend gesplittet. Das Frontend wird in einzelnen Komponenten geschrieben. Die Datei "app.vue" dient als Hauptdokument für alle einzelnen Komponenten und verbindet diese.
